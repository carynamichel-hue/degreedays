# Degree Days

**Pest scouting by growing degree-days, for nurseries.** Which pests are
active now, which are coming, and where to scout — from the weather at your
own location. Free, no accounts, your data stays on your device.

**Live: https://carynamichel-hue.github.io/degreedays/** — open it on a phone
and "Add to Home Screen". The 📖 guide inside explains everything.

This repository holds only the **built site**. The source lives with the
farm's other tools. What you *can* read here is [`prompts/`](prompts/): how
the app was built in a day with an AI coding assistant — the brief, each
step, the review rounds in the grower's words, and how to make it yours.

Pest thresholds: Rutgers Nursery & Landscape Pest Scouting Guide (beta 2023,
T. Waller, NJAES), compiled from Rutgers, Cornell, Penn State, Michigan State,
UNH, Maryland, Delaware, NC State and the PA Department of Agriculture — for
scouting purposes only.

Built by Caryn A. Michel, Overdevest Nurseries, with Claude Code.
